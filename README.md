# Filzra 全球文件模板资源库

Filzra 静态资源目录面向需要了解 KYC（Know Your Customer，了解你的客户）常见文件类型、格式和信息结构的个人、产品团队及合规从业者。网站集中展示全球不同国家和地区的文件模板条目，帮助访客按名称、地区和类别查找资料，并通过预览了解条目外观。目录覆盖驾照、护照、ID 卡、水电账单、银行账单、收入及存款证明，以及企业文件、证书等类别；资源条目可能标注 PSD、Word、PDF 等格式。

## KYC 文件目录浏览功能（非认证服务）

- **按类别查找：** 从驾照、护照、ID 卡等身份类条目，切换至水电账单、银行账单、收入证明等地址或财务类条目，便于快速定位所需了解的文件类别。
- **按国家/地区浏览：** 使用资源目录查看不同地区收录的条目，辅助跨地区产品设计、合规需求梳理和文件类型研究。目录中的国家/地区标签代表资源分类信息，不等同于对当地法规或机构要求的说明。
- **关键词检索：** 按文件名称、国家/地区或文件类型查找资源；搜索结果可进入静态详情页查看标题、类别和预览图。
- **预览与比较：** 页面提供与资源记录匹配的本地预览图片，方便查看版面层级、常见字段区域和视觉布局，用于参考信息架构、界面原型或内部培训材料。
- **静态目录访问：** 资源介绍、分类和预览由 GitHub Pages 静态站点提供。站点不提供身份核验、文件真实性鉴定、KYC 审批、账户开立或资料上传功能。

## 非认证类参考场景

1. **版式与信息架构研究：** 以公开预览了解文件类别、版面层级和常见信息区域，用于非生产环境的视觉研究或术语整理，不据此制作、修改或提交认证材料。
2. **静态界面原型：** 设计与研发团队可在不连接真实认证流程的演示页面中研究分类导航和说明文案。原型数据须为明显虚构、不可用于身份识别的占位内容，不得仿制真实凭证或接入真实注册、审核流程。
3. **内部教育展示：** 可用于解释文件类别名称和目录组织方式。展示内容需标明“示例/非官方/不可用于认证”，不得将预览描述为真实、有效或可通过审核的证明。
4. **目录检索与本地化：** 研究人员可按地区和类型整理公开条目、进行术语对照或检查站点导航；此类活动仅限目录和页面本身，不构成 KYC/KYB 操作建议或文件合规判断。
