# Filzra 全球文件模板资源库

这是 Filzra 资源目录的静态浏览版，便于按文件类型或国家/地区查找资源。站点整理驾照、护照、ID 卡、水电账单、银行账单、收入及存款证明等模板条目，并提供分类信息和预览图。资源涉及 PSD、Word、PDF 格式，以及地址证明、金融文件、公司资料和证书等类别。

## 站点内容

- **首页与检索：** 支持按名称、国家/地区和文件类型搜索，并可浏览资源库、分类目录及详情页。
- **分类与详情：** 展示驾照、护照、ID 卡、账单和证明文件；详情页提供标题、地区、类型及对应预览。
- **本地图片：** 当前目录包含 1,019 条资源记录，其中 1,013 条有可用预览图，图片由本仓库的 `assets/images/` 提供；其余条目保留文字信息，不显示不匹配图片。
- **搜索引擎信息：** 页面设有标题、摘要和规范网址，并提供页面/图片站点地图及 `robots.txt`。搜索引擎是否收录及排名由其自行决定。

## 官方服务

本项目仅用于静态浏览 Filzra 资源目录。登录、注册、购买、VIP 会员、下载及其他在线服务，请访问 [Filzra 官方网站](https://www.filzra.com/)，相关操作以官方站页面为准。
