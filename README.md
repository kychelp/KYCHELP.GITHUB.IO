# Filzra 全球文件模板资源库

Filzra 静态资源目录面向需要了解 KYC（Know Your Customer，了解你的客户）常见文件类型、格式和信息结构的个人、产品团队及合规从业者。网站集中展示全球不同国家和地区的文件模板条目，帮助访客按名称、地区和类别查找资料，并通过预览了解条目外观。目录覆盖驾照、护照、ID 卡、水电账单、银行账单、收入及存款证明，以及企业文件、证书等类别；资源条目可能标注 PSD、Word、PDF 等格式。

## KYC 相关功能

- **按类别查找：** 从驾照、护照、ID 卡等身份类条目，切换至水电账单、银行账单、收入证明等地址或财务类条目，便于快速定位所需了解的文件类别。
- **按国家/地区浏览：** 使用资源目录查看不同地区收录的条目，辅助跨地区产品设计、合规需求梳理和文件类型研究。目录中的国家/地区标签代表资源分类信息，不等同于对当地法规或机构要求的说明。
- **关键词检索：** 按文件名称、国家/地区或文件类型查找资源；搜索结果可进入静态详情页查看标题、类别和预览图。
- **预览与比较：** 页面提供与资源记录匹配的本地预览图片，方便查看版面层级、常见字段区域和视觉布局，用于参考信息架构、界面原型或内部培训材料。
- **静态目录访问：** 资源介绍、分类和预览由 GitHub Pages 静态站点提供。站点不提供身份核验、文件真实性鉴定、KYC 审批、账户开立或资料上传功能。

## 适用场景

1. **KYC 流程与产品规划：** 产品经理、设计师和合规团队可用目录了解身份、地址、财务及企业资料等常见类别，整理真实业务所需的材料清单，规划上传提示、文件分类、审核队列和用户指引。最终材料要求应以提供服务的金融机构、平台及适用地区的正式规定为准。
2. **界面原型和可用性测试：** 设计与研发团队可参考公开展示的版式，搭建不含真实个人信息的界面草图、测试页面或演示流程，检查文件类型选择、拍摄提示、信息录入和错误提示是否清楚。测试数据应使用明确标注的虚构样例，不应冒充真实凭证。
3. **员工培训与流程沟通：** 培训人员可借助分类和预览说明不同文件类别的名称与页面结构，帮助团队理解审核流程中的材料归类和人工复核环节。预览仅用于识别版面，不代表文件真实、有效或满足特定机构的审核标准。
4. **跨地区信息整理：** 研究人员可按国家/地区和文件类型浏览目录，为本地化调研、术语对照和需求访谈建立初步索引。实际项目应另行核对最新官方指南、当地法律要求及服务提供方的接受标准，不能仅凭目录标签推断合规结论。
5. **个人材料准备参考：** 访客可通过分类了解 KYC 流程可能涉及的材料类别，再向办理机构确认其当前接受的文件、有效期、语言、拍摄质量和提交渠道。办理真实验证时，应使用本人合法取得、内容真实且未经篡改的原始文件，并通过机构的官方安全入口提交。

## 重要说明

本项目是静态资源浏览目录，不是 KYC 服务商，也不代表任何银行、政府部门或身份验证机构。目录中的模板、版式和预览图仅用于信息浏览、设计研究、教学演示或合规测试环境中的虚构样例；它们不是身份证明、地址证明、银行记录或其他官方凭证，不能替代真实文件，也不能证明持有人身份、住址、收入或账户状态。请勿编辑模板来冒充真实文件、提交虚假材料或规避机构审核。任何正式 KYC 验证均应依照机构要求，使用真实、准确、有效的资料，并遵守适用的隐私和数据保护规则。
